# النشر على Google Play

كل ما يلزم لرفع سُنّتي إلى المتجر موجود في هذا المجلد وفي `docs/`. التطبيق يُغلَّف
كـ Trusted Web Activity، أي أن حزمة أندرويد تفتح الموقع نفسه بلا شريط متصفح، فما
يُصلَح في الموقع يصل إلى من ثبّت التطبيق دون رفع حزمة جديدة.

## ما هو جاهز

| الملف | ما هو |
| --- | --- |
| `play/twa-manifest.json` | إعدادات bubblewrap كاملة، الاسم واللون والاختصارات |
| `docs/.well-known/assetlinks.json` | ربط الحزمة بالنطاق، ينقصه بصمتا المفتاح |
| `docs/manifest.webmanifest` | إحدى عشرة أيقونة وخمس لقطات وثلاثة اختصارات |
| `docs/icons/play-1024.png` | أيقونة المتجر، ألف وأربع وعشرون بلا شفافية |
| `docs/screens/*.png` | خمس لقطات من التطبيق نفسه |
| `docs/splash/*.png` | أربع وعشرون شاشة بدء لأجهزة أبل |
| `docs/privacy.html` | سياسة الخصوصية، والمتجر يشترطها |

## الخطوات

```bash
npm install -g @bubblewrap/cli
cd play
bubblewrap init --manifest https://siteq8.github.io/Quran_Sunna/manifest.webmanifest
# أجب بما في twa-manifest.json، أو انسخه مكان الملف الذي يولّده
bubblewrap build
```

يخرج لك `app-release-bundle.aab` وهو ما يُرفع، ومعه `android.keystore` فاحفظه في
مأمن، إذ لا يمكن تحديث التطبيق بعد ذلك بغيره.

ثم خذ بصمة المفتاح:

```bash
keytool -list -v -keystore android.keystore -alias sunnati | grep SHA256
```

وضعها مكان `REPLACE_WITH_THE_SHA256_OF_YOUR_UPLOAD_KEY` في
`docs/.well-known/assetlinks.json`، وبعد أول رفع خذ من Play Console بصمة مفتاح
التوقيع الذي يولّده المتجر وضعها في الموضع الثاني، ثم ارفع الملف إلى الموقع. بغير
هاتين البصمتين يفتح التطبيق بشريط متصفح ظاهر.

## نص الصفحة في المتجر

### الاسم
```
سُنّتي، القرآن والأذكار والمواقيت
```

### الوصف القصير
```
المصحف كاملاً ومواقيت الصلاة والأذكار والقبلة، يعمل بلا إنترنت وبلا إعلانات.
```

### الوصف الكامل
```
سُنّتي رفيق يومي في العبادة، يحمل المصحف كاملاً ومواقيت الصلاة والأذكار وتتبع
السنن، ويعمل كله في جهازك بلا إنترنت وبلا حساب وبلا إعلانات وبلا تتبع.

■ مواقيت الصلاة
حساب فلكي على الجهاز بخمس عشرة طريقة معتمدة من رابطة العالم الإسلامي وأم القرى
والهيئة المصرية وكراتشي وديانت وغيرها، مع مذهبي العصر عند الجمهور والحنفية،
وتصحيح لخطوط العرض العالية التي لا يغيب فيها الشفق. والمواقيت مربوطة بالمنطقة
الزمنية للمدينة فتتبع تغيّر الساعة، ويوم الجمعة تُسمّى الصلاة باسمها.

■ المصحف
النص كامل برواية حفص عن عاصم بالرسم العثماني، ستة آلاف ومئتان وست وثلاثون آية
محفوظة في جهازك. تصفّح بالسور أو بالأجزاء الثلاثين، ومواضع السجدة معلّمة، واضغط
أي آية لتحفظها أو تشاركها أو تسمعها أو تقرأ تفسيرها. وبحث يفهم الرسم العثماني
والإملاء المعتاد معاً، فمن كتب الصابرين ومن كتب الصبرين وصل إلى الآيات نفسها.

■ الأذكار
ستة عشر قسماً من حصن المسلم، لكل ذكر عدّاده الذي يحفظ موضعه في يومك.

■ تتبع السنن
ورد يومي وسنن موزّعة على أوقات اليوم، في مجموعات تُطوى وتُفتح، مع شبكة تبيّن آخر
ثلاثين يوماً وسلسلة أيامك المتصلة.

■ أدوات أخرى
القبلة ببوصلة تدور مع الجهاز، والمسبحة بأهداف محفوظة، وخطة ختمة تفتح المصحف عند
الصفحة التي بلغتها، والأربعون النووية والأدعية المأثورة والرقية الشرعية، والتقويم
الهجري بالمناسبات، وإذاعة القرآن بمؤقت إيقاف، وسبعة عشر قارئاً، ونسخة احتياطية
تصدّر كل ما سجّلته في ملف واحد.

■ خصوصيتك
لا يجمع التطبيق عنك شيئاً ولا يرسل عنك شيئاً. كل ما تسجّله يبقى في جهازك، ولا
يحتاج الإنترنت إلا للتلاوة الصوتية والإذاعة والتفسير حين تطلبها أنت.

التطبيق مفتوح المصدر برخصة MIT، والشيفرة كاملة متاحة للمراجعة.
```

## إفصاح أمان البيانات

يسأل المتجر عن جمع البيانات، والجواب في كل بند: لا. التطبيق لا يجمع ولا يشارك
شيئاً. الموقع الجغرافي يُستعمل على الجهاز لحساب المواقيت والقبلة ولا يُرسل، وهو
اختياري إذ يمكن اختيار مدينة من القائمة بدلاً منه.

| السؤال | الجواب |
| --- | --- |
| هل يجمع التطبيق بيانات أو يشاركها؟ | لا |
| هل البيانات مشفّرة أثناء النقل؟ | لا تُنقل بيانات أصلاً |
| هل يمكن للمستخدم طلب حذف بياناته؟ | نعم، من شاشة الإعدادات |
