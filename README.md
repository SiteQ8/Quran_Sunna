## ما الذي يميّز هذا التطبيق

أكثر التطبيقات الإسلامية تطلب المواقيت من خادم بعيد وتنزّل نص الآية عند كل فتحة، فإذا انقطع الإنترنت توقف كل شيء. سُنّتي يقلب هذا الترتيب، إذ يحفظ المصحف كاملاً في جهازك ويحسب أوقات الصلاة فلكياً على الجهاز نفسه، ثم لا يبقى للشبكة إلا ثلاثة أشياء وهي التلاوة الصوتية والإذاعة والتفسير.

لا حساب ولا تسجيل ولا تتبع ولا إعلانات، وكل ما تسجّله من ورد وأذكار وآيات محفوظة يبقى في جهازك وحده ويمكنك تصديره متى شئت.

## المميزات

### أوقات الصلاة

حساب فلكي كامل على الجهاز بخمس عشرة طريقة معتمدة من رابطة العالم الإسلامي وأم القرى والهيئة المصرية وكراتشي وديانت وغيرها، مع مذهبي العصر عند الجمهور والحنفية، وثلاث طرائق لتصحيح خطوط العرض العالية التي لا يغيب فيها الشفق.

قوس على الشاشة الرئيسية يبيّن كم مضى من الوقت بين الصلاتين وكم بقي، ولون التطبيق كله يتغير مع الوقت الداخل فيه فللفجر لون وللضحى آخر وهكذا إلى العشاء.

### المصحف

النص كامل برواية حفص عن عاصم بالرسم العثماني، ستة آلاف ومئتان وست وثلاثون آية محفوظة معك.

- تصفح بالسور أو بالأجزاء الثلاثين
- مواضع السجدة معلّمة في النص
- اضغط أي آية ليفتح لك ما يخصها من حفظ ومشاركة وتلاوة وتفسير
- بحث في كلمات القرآن يعمل بالتشكيل وبدونه
- علامة تعيدك إلى حيث توقفت
- خطة ختمة توزّع الصفحات على المدة التي تختارها وتخبرك أمتقدم أنت أم متأخر

**البحث يفهم الرسمين معاً.** الرسم العثماني يخفي الألف الطويلة في علامة صغيرة فوق الحرف، فكلمة الصابرين مكتوبة في المصحف الصٰبرين والصلاة مكتوبة الصلوٰة، والقارئ الذي يكتب الإملاء المعتاد كان يخرج بلا نتيجة. صار البحث الآن يطابق الرسمين، فمن كتب الصابرين ومن كتب الصبرين وصل إلى الآيات نفسها.

### الأذكار

ستة عشر قسماً من حصن المسلم فيها أذكار الصباح والمساء والنوم والاستيقاظ وما بعد الصلاة والوضوء والطعام والسفر والمنزل والمسجد والمطر والكرب، مع أسماء الله الحسنى التسعة والتسعين.

لكل ذكر عدّاده الخاص ينزل مع كل ضغطة ويحفظ موضعه في يومك، فإن خرجت وعدت وجدته حيث تركته.

### تتبع السنن

أربعون بنداً بين ورد يومي وسنن موزعة على أوقات اليوم، مع شبكة تبيّن آخر ثلاثين يوماً وسلسلة أيامك المتصلة. الشاشة الرئيسية تعرض سنن الوقت الداخل فيه وحده حتى لا تزدحم عليك القائمة.

### أدوات أخرى

- **القبلة** بحساب دائرة عظمى مع بوصلة تدور مع الجهاز ومسافة إلى الكعبة
- **المسبحة** بثماني صيغ لكل واحدة هدفها، والمجموع محفوظ ليومك
- **الأربعون النووية** والأدعية المأثورة والرقية الشرعية
- **التقويم الهجري** بالمناسبات والمواسم مع تعديل يدوي لليوم إن اختلف الحساب عن رؤية بلدك
- **إذاعة القرآن** بتسع محطات ومؤقت إيقاف
- **سبعة عشر قارئاً** للتلاوة
- **نسخة احتياطية** تصدّر كل ما سجّلته في ملف واحد وتستعيده متى شئت

## يعمل بلا إنترنت

التطبيق يثبَّت على الجهاز مثل أي تطبيق، ويحفظ عامل الخدمة كل ملفاته ونص المصحف عند أول زيارة.

| يعمل بلا شبكة | يحتاج شبكة |
| --- | --- |
| المصحف والبحث والقراءة | تلاوة القارئ |
| أوقات الصلاة والقبلة | الإذاعة المباشرة |
| الأذكار والمسبحة والسنن | التفسير |
| التقويم والأدعية والأحاديث | |

## البنية

بلا إطار عمل وبلا خطوة بناء، فالملف الذي يُرفع هو الملف الذي يعمل.

```
docs/
  index.html            الواجهة كاملة وتسع عشرة شاشة
  css/style.css         التصميم وسمة فاتحة وأخرى داكنة
  js/prayer-engine.js   الحساب الفلكي لأوقات الصلاة والقبلة
  js/hijri.js           التقويم الهجري والمناسبات
  js/store.js           الإعدادات وسجل اليوم والنسخ الاحتياطية
  js/mushaf.js          نص المصحف والبحث وخطة الختمة
  js/app.js             التنقل والعرض والتفاعل
  data/                 المصحف والأذكار والأحاديث والمدن والقرّاء
  sw.js                 عامل الخدمة للعمل بلا إنترنت
test/                   مئة وسبعة وعشرون اختباراً تُشغَّل بـ node --test
```

## التشغيل محلياً

```bash
git clone https://github.com/SiteQ8/Quran_Sunna.git
cd Quran_Sunna
python3 -m http.server 8000 --directory docs
```

ثم افتح `http://localhost:8000`.

## الاختبارات

```bash
npm install jsdom
node --test test/
```

مئة وسبعة وعشرون اختباراً تغطي الحساب الفلكي والتقويم الهجري والتخزين ونص المصحف، ثم تقود الواجهة كاملة داخل jsdom كما يقودها إنسان، فتفتح السور وتعدّ الأذكار وتضبط الإعدادات وتتحقق من كل شاشة.
